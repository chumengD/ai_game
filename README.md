# LoveHeart

《LoveHeart》是一款以现代校园与都市日常为背景的**恋爱互动视觉小说（GalGame）**。

玩家将扮演一名在婚礼上意外邂逅心动对象的男生，从抢捧花时的一次碰撞开始，通过微信破冰、朋友圈互动、校园偶遇、生病关怀、夜晚散步、下午茶约会，逐步走向游乐园摩天轮上的最终告白。

作品的核心不是"选对选项就恋爱成功"，而是让玩家在一次次对话中学习**如何真诚表达、理解情绪、把握分寸**。直接冒进、敷衍关心、过度讨好都会带来不同反馈；认真倾听、记住细节、尊重对方感受则会让关系自然升温。游戏通过**隐藏好感度系统**记录玩家的长期选择，并在女主视角章节中回看这些互动，让玩家看到自己行为在对方心里的真实影响。

在玩法上，我们结合了传统视觉小说分支、微信式聊天界面、朋友圈点赞评论、隐藏成就、多结局判定以及 AI 自由聊天机制。玩家不仅能在固定剧情中做选择，也能通过更接近日常社交的方式参与关系推进。最终根据全程累计的好感与互动质量，游戏将导向**"遗憾擦肩""平淡相守"或"心动圆满"**三种结局。

---

## 技术

游戏内设有隐藏的好感度系统，以及微信聊天系统。聊天系统包含**按剧本走的聊天模块**与 **AI 聊天模块**。

- 游戏引擎：**Ren'Py**
- 主力 AI 工具：**Codex**，辅助 AI 工具：**Claude Code**（接入 DeepSeek V4）

---

## AI

游戏内置了一个基于 **DeepSeek API** 的自由聊天功能，玩家可以在微信界面中自由输入文字与 AI 驱动的女主交流。AI 会根据上下文理解情绪（喜/怒/哀/乐/常），情绪判断会影响好感度。不过该功能目前作为**支线玩法**存在，主线故事仍以预写剧本为主。

CG 的生成流程是先人工提供画风参考，然后使用 **Codex** 生成。
